`cosmoz-toggle-group` takes `size="sm"` (and `toggleGroup({ size: 'sm' })`). It renders 32px high with xs text, the same box as `cosmoz-tabs-next` segmented `sm`, so a picker in a toolbar lines up with sm buttons and tab bars next to it. The default size is unchanged.
